== Description ==

Bookora is a modern Hotel Booking WordPress theme built for hotels, resorts, hostels and travel businesses. It pairs a polished front-end with a companion plugin (bookora-plugin) that adds Elementor templates, mega-menu support and theme options.

Key features:

* Hotel & room listings with WooCommerce booking integration
* Drag-and-drop Elementor builder with custom bookora widgets
* Mega menu support with custom menu meta
* One-click demo import
* Theme license activation via Lemon Squeezy
* Fully responsive, RTL support and translation-ready

== Installation ==

1. Upload the `bookora` theme folder to the `/wp-content/themes/` directory, or install the ZIP through Appearance > Themes > Add New > Upload Theme.
2. Activate the theme through the Appearance > Themes menu.
3. Install and activate the required plugins (the theme will prompt you): bookora-plugin, Elementor, WooCommerce, Contact Form 7, One Click Demo Import, Directorist and Mailchimp for WordPress.
4. Go to Appearance > Theme License and enter your Lemon Squeezy license key to activate the theme.
5. Import the demo content from Appearance > Import Demo Data (or the Bookora dashboard).

== Frequently Asked Questions ==

= My license won't activate =
On the Theme License page, first enter your Lemon Squeezy API key and click "Save API Key", then enter your license key and click "Activate License". Both the API key and the license key must be valid.

= The theme asks for the companion plugin =
Install bookora-plugin from the Bookora dashboard; several features depend on it.
