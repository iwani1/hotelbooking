=== Bookora Reception ===
Requires at least: 6.8
Requires PHP: 8.0
Stable tag: 1.0.0
License: GPL-2.0-or-later

Staff-only physical-room reservations in WordPress admin. Administrators and users assigned the Receptionist role can add rooms, create reservations, check guests in and out, and cancel confirmed reservations. Availability checks only cover reservations made by this plugin. No payments, rates, email confirmations, public booking, or external channel synchronization are provided.

Install and activate the plugin, add rooms under Reception > Rooms, and make reservations under Reception > Reservations. Data remains in the WordPress database on deactivation. Back up data and review privacy and security before real-world use. Network-wide multisite activation is not supported.
